# Project Archives

This directory contains archived files from the VitalSense project that are kept for reference but are no longer actively used.

## Directory Structure

- `components/` - Archived React components (from `src/components/_archive/`)
- `src/` - Archived source files (from `src/_archive/`)
- `docs/` - Archived documentation (from `docs/_archive/`)
- `scripts/` - Archived scripts (from `scripts/_archive/`)
- `server/` - Archived server implementations (from `server/_archive/`)
- `config/` - Archived configuration files (from `config/_archive/`)

## Purpose

These archives are maintained for:
- **Historical reference** - Understanding project evolution
- **Code recovery** - Retrieving deprecated features if needed
- **Documentation** - Preserving implementation details

## Cleanup Policy

Archived files are kept indefinitely unless:
- They exceed 1GB total size
- They contain security vulnerabilities
- They are explicitly requested for deletion
