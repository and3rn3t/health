## 📝 Asset Requirements

See `docs/APP_STORE_ASSETS_GUIDE.md` for complete requirements and specifications.

## ✅ Checklist

- [ ] Create screenshots for all required device sizes
- [ ] Create app preview video (15-30 seconds)
- [ ] Prepare 1024x1024 app icon
- [ ] Write app description (max 4000 characters)
- [ ] Write keywords (max 100 characters)
- [ ] Write "What's New" for version 1.0
- [ ] Prepare privacy policy URL
- [ ] Prepare support URL
- [ ] Complete age rating questionnaire
- [ ] Select app categories

## 🎨 Asset Creation Tips

1. **Use Real Devices:** Best quality comes from actual devices
2. **Remove Personal Info:** Hide sensitive data in screenshots
3. **Show Key Features:** Dashboard, Gait Analysis, Health Metrics, etc.
4. **Consistent Design:** Same app state across screenshots
5. **Professional Quality:** High resolution, clear text, good contrast
