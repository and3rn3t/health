Dataset Browser

Served by /catalog endpoints. Start with: npm run catalog:api

💡 Quick Test: Each section has a "📋 Load Sample Data" button to populate fields with test values. Use window.TestData in console to access all sample data programmatically.

    Collections

      NDVI demo

      Runs POST /analysis/ndvi on a small in-page sample.

      Upload JSON

      Upload a small JSON file; it will be stored temporarily and retrievable by id.

      NDVI from CSV

      Paste comma/space/newline separated values for NIR and RED. Then run.

      NDWI from CSV

      Paste comma/space/newline separated values for Green and NIR. NDWI = (Green - NIR) / (Green + NIR)

      NDMI from CSV

      Paste comma/space/newline separated values for NIR and SWIR. NDMI = (NIR - SWIR) / (NIR + SWIR)

      Cloud/Shadow Masking

      Mask clouds (high brightness) and/or shadows (low brightness) from RGB imagery. Toggle mask type and adjust thresholds.

      Tile Viewer

      View raster tiles with different style presets. Tiles are cached for performance.

      Click "Test Tile" to load a sample tile

      Vector Spatial Operations

      Spatial joins, buffers, and proximity queries on vector features.

      Spatial Join

      Find features that intersect with a query bounding box.

      Buffer

      Create a circular buffer around a point.

      Proximity / Nearest Neighbor

      Find nearest point features to a query point.

      LiDAR Processing

      Ground classification, DTM/DSM generation from point cloud data.

      Ground/Non-Ground Classification

      Classify LiDAR points as ground (2) or non-ground (1).

      DTM Generation

      Generate Digital Terrain Model from ground-classified points.

      DSM Generation

      Generate Digital Surface Model from all points (highest elevation per cell).

      Canopy Height Model (CHM)

      Generate CHM from DSM and DTM (CHM = DSM - DTM). Paste DSM and DTM JSON results.

      Terrain Derivatives (Slope/Aspect)

      Calculate slope and aspect from DTM. Paste DTM JSON result.

      Feature Extraction (Buildings & Trees)

      Extract buildings and trees from CHM using rule-based detection. Paste CHM JSON result.

      3D Tiles Viewer

      View 3D point cloud tiles. Simple JSON-based format for visualization.

      Click "Test 3D Tile" to load a sample 3D tile
